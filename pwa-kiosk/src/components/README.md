# Components

Reusable UI components for the PWA kiosk.

- `LoginScreen.jsx`: admin login screen.
- `KioskHeader.jsx`: top kiosk title and logout action.
- `CameraLayer.jsx`: live camera preview background.
- `ScanGuide.jsx`: visual scan guide.
- `KioskControls.jsx`: employee selection and attendance action panel.
- `EmployeePicker.jsx`: searchable employee selector.
- `StatusMessage.jsx`: status banner.
