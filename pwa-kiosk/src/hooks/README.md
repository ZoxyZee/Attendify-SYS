# Hooks

Browser and session hooks for the PWA kiosk.

- `useAuthSession.js`: login/logout and token persistence.
- `useCameraPreview.js`: camera permission and video stream lifecycle.
- `useOnlineStatus.js`: browser online/offline state.
- `useRealtimeAttendance.js`: Server-Sent Events subscription.
- `useServiceWorker.js`: PWA service worker registration.
