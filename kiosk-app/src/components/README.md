# Mobile Components

Reusable React Native UI components.

- `KioskSetupScreen.jsx`: first-time login and backend URL setup
- `AdminPanel.jsx`: admin mode, settings, enrollment, sync tools
- `KioskCamera.jsx`: camera wrapper
- `EnrollmentCaptureOverlay.jsx`: face sample capture UI
- `SuccessOverlay.jsx`: attendance success feedback
- `PinUnlockModal.jsx`: local admin PIN modal
