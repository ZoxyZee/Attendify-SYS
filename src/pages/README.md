# Web Pages

Route-level screens for the web dashboard.

- `Login.jsx`: sign in and company registration
- `Dashboard.jsx`: operational summary
- `Employees.jsx`: employee management
- `FaceRegistry.jsx`: web face registry tools
- `Attendance.jsx`: attendance review and web scanning
- `Devices.jsx`: kiosk/device management
- `Reports.jsx`: reporting/export view
- `Settings.jsx`: company/user settings
